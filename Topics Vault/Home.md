# School Notes — by Topic

This vault is a topic-organized copy of my class notes. Instead of one folder per class per semester, notes are grouped by the underlying subject or skill, so ideas that showed up in two different classes sit near each other and link to each other. Open the graph view to see the overlap.

Each note keeps a `source-class` and `source-semester` field in its frontmatter so I can still tell which class it came from. The `Assets` folder holds every embedded image, syllabus PDF, and slide deck from the original vault.
