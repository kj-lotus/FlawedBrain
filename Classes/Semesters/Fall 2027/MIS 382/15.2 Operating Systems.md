### Learning Objectives

- Understand what an operating system is and why computing devices need one
- See how embedded systems extend Moore's Law, letting firms build smarter products and services

### What an OS Actually Does

The **operating system (OS)** controls computer hardware and gives programmers a common set of commands to work with. It sits between the hardware and the user, and between the hardware and the software developer.

Nearly every computing device runs some form of OS: desktops, laptops, servers, phones, game consoles, set top boxes, Kindles, AR and VR headsets (Oculus, Vision Pro), smart watches, smart appliances.

**Who makes them:**

- Apple and Nintendo build proprietary OS for their own hardware
- Microsoft licenses Windows to other manufacturers (Dell, Diebold ATMs, etc.)
- Specialty firms like Wind River build OS for non PC devices such as cars, video editing systems, and fighter jet control panels

### Why the OS Matters to Users

Comparing a PC to a Mac shows how much an OS shapes the experience, even when the app is identical (like Firefox on both). Menus, scroll bars, window borders, and dialogue boxes all look and behave differently because each team built its own **graphical user interface (UI or GUI)**.

> **GUI** is the mechanism through which users interact with a device: windows, scroll bars, buttons, menus, dialogue boxes, and also touch screens, motion controllers, or tactile devices for accessibility.

A consistent UI across programs lowers training costs and reduces user error. Tools like Macintosh Finder and Windows Explorer are examples of OS components that manage files and hardware directly.

### Why the OS Matters to Developers

The OS gives programmers a shared set of commands so they do not have to write custom code for every piece of hardware. This cuts complexity, speeds up development, and reduces bugs.

Example: Nintendo's Switch OS gives developers standard ways to access controllers, play sound, draw graphics, and save files. Without that standard layer, games would take longer to build, cost more, look worse, and there would be fewer of them.

Apple's App Store is the bigger version of this idea. Once Apple gave developers a solid, easy to use standard for iOS, software development exploded (about 50,000 apps within a year, around 2 million today). A well designed OS and development platform can trigger real network effects, which shows the OS is not just a technical layer, it has strategic business value.

### Firmware and the BIOS

Most PCs store their OS on the hard drive so it can be upgraded easily. Smaller, special purpose devices often store their OS on nonvolatile memory, usually read only memory (ROM) chips.

> **Firmware**: software stored on nonvolatile memory chips rather than a hard drive or disc. Despite the name, most firmware can still be upgraded online or via a connected device.

> **BIOS (Basic Input Output System)**: the lowest level firmware, containing the base commands for controlling hardware. It handles things like reading files from storage and booting the OS when a device restarts. BIOS sits a level below the OS itself.

Even though ROM implies "read only," most modern firmware ROM can actually be rewritten, which is how firmware updates work.

### Embedded Systems and IoT

> **Embedded systems**: special purpose software built into physical products, often stored as firmware. They make devices "smarter" by sharing usage data, diagnosing problems, flagging maintenance needs, sending alerts, or letting a device take commands from another system.

As computing gets cheaper, embedded systems show up everywhere: cars, picture frames, speakers, aircraft engines, photocopiers, HVAC systems, cow tracking collars, pipeline sensors.

When embedded devices use microprocessors to talk to each other (think Nest thermostats, app controlled locks and lighting), that is the **Internet of Things (IoT)**.

### The Moore's Law Connection

Moore's Law (cheaper, faster computing over time) is what makes embedded systems economically possible in the first place. Cheaper chips mean more products can afford to have smart, connected components built in.

### Case Example: Otis Elevator

Otis embeds systems in its elevators, escalators, and moving walkways to signal when maintenance is needed. This creates four strategic benefits:

1. Products contact Otis directly, generating a steady service business and making it harder for third parties to compete for that service work
2. Maintenance happens based on actual need (low lubricant, worn part) instead of a fixed guessed schedule, which is cheaper and more reliable
3. Failures get detected immediately, often dispatching a technician before the customer even calls
4. Failure and reliability data feeds back to Otis R&D, improving future product design

This is a clean example of embedded systems turning into sustained competitive advantage.

### Key Takeaways

- The OS controls hardware and gives programmers a common command set
- Almost every computing device has one, from servers to phones to the Mars Rover
- Some firms build proprietary OS, some license from commercial vendors, some use open source
- Embedded systems are special purpose systems built into everyday products like thermostats, locks, cars, and elevators
- Embedded systems boost efficiency and reliability, and can create entirely new business lines or reinforce a competitive edge
